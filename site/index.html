    Checks run about every minute. If they stop, this page shows “Monitoring delayed” instead of a status it cannot confirm. Short interruptions between checks may not be observed. The percentage describes successful checks, not a promised uptime or service-level agreement.

    Two failed checks in a row open an outage issue for the operator. Recovery closes it. A separate watchdog flags delayed monitoring. Notification delivery depends on the operator’s GitHub notification settings; this page does not claim a staffed response.
